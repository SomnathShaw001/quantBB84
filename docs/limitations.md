# Limitations of this Software Simulator

This software application is an interactive educational and research simulator designed to elucidate the core principles of the BB84 protocol. The following boundaries and deliberate physical approximations apply:

1. **Idealized Single-Photon Source Assumption:**
   The simulator assumes true on-demand single-photon generation. In commercial QKD networks, attenuated laser diodes (weak coherent pulses following a Poisson distribution $P(n) = \frac{\mu^n e^{-\mu}}{n!}$) are utilized. These multi-photon pulses are vulnerable to **Photon-Number-Splitting (PNS) attacks**, which require **Decoy-State BB84** protocols to counteract.

2. **Optical Channel Noise vs. Eavesdropping Ambiguity:**
   In real fiber links, thermal fluctuations, Rayleigh backscattering, polarization mode dispersion, and Raman noise contribute to an intrinsic channel QBER ($\approx 1\text{--}3\%$). The protocol cannot distinguish whether an error originated from Eve or from natural fiber attenuation. Consequently, all noise is conservatively attributed to Eve.

3. **Detector Imperfections:**
   Real Single-Photon Avalanche Diodes (SPADs) and Superconducting Nanowire Single-Photon Detectors (SNSPDs) exhibit dark count rates, finite quantum detection efficiency ($\eta < 1$), timing jitter, and dead times. These are modeled here as uniform random photon losses and depolarizing error channels.

4. **Finite-Key Analysis vs. Asymptotic Bounds:**
   The parameter estimation threshold ($11\%$) is derived from the asymptotic limit ($N \rightarrow \infty$). For finite block sizes ($N \le 10^4$), statistical fluctuations require composable security bounds with security parameters $\epsilon_{\text{sec}}$ and $\epsilon_{\text{cor}}$, yielding lower secret key lengths than the asymptotic formula.

5. **No Cryptographic Guarantees:**
   Outputs generated by this simulator must **never** be used to protect production networks or real secrets. The keys are intended solely for classroom demonstrations, academic evaluations, and viva voce discussions.
